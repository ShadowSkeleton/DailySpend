# DailySpend legal and support site

These static pages are designed for GitHub Pages' free `/docs` publishing source.
They contain no scripts, forms, analytics, or personal data.

To publish after choosing the GitHub account that will own the public URL:

1. Push this repository to that account.
2. In GitHub repository settings, enable Pages from the default branch and `/docs` folder.
3. Enforce HTTPS.
4. Use the resulting `/privacy/` and `/support/` URLs in App Store Connect and the app.

See `APP_STORE_RELEASE_CHECKLIST.md` for the remaining signed-build and
real-device submission checks.
