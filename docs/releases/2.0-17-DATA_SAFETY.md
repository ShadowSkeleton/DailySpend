## Crash in 2.0 (16) TestFlight

| Item | Value |
|---|---|
| Count | 1 crash, 1 device (iPhone18,4, iOS 26.6.2), build 16, November 2, 2026 |
| Termination | `0xdead10cc`: iOS stopped DailySpend because it was suspended while holding a lock on its database file in the shared App Group folder |
| When | 0.6 s after launch. Main thread: `MoneyStoreMigration.backfillMissingMinorUnits` fetching records (unchanged since 1.0). Another thread: iCloud (CloudKit) setup reading the same store |
| Likely cause | A background launch (iCloud sync push) that iOS suspended during the startup fetch. The tester most likely saw nothing |
| Data risk | None found: the fetch only reads, and SQLite is transactional, so an interrupted read leaves the file as it was |
| New in 2.0? | No: the same startup path exists in 1.0 |
| Decision | No change in 2.0 (17), to keep the stable persistence path untouched. Possible 2.0.x item after a separate persistence review: skip the full fetch once the backfill has completed |
