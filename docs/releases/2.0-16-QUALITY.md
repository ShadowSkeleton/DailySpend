| Finding | Severity | Fix |
|---|---|---|

| Scan card store name and "Food · Today" wrapped | Low, observed | Single-line labels, wider card |

| Action button icon unclear | Low, observed | `button.programmable` |
| Tour container ID hid button IDs from VoiceOver/UI tests | Medium, reproduced | `.accessibilityElement(children: .contain)` |
| Tour buttons stretched across the iPad (and open Duo) width | Low, observed on iPad Pro 13-inch | Button area capped at 480 points |
| Tour text ran into the page dots on the open Duo (landscape, 669 points tall) | Medium, observed | The picture steps down to 64% when space is short, before the page scrolls; also helps iPhones held sideways |

Open suggestions (subjective, not blocking): "Skip" is secondary gray, the
system's usual weight; the Split picture's shares row fades in late and can
be missed on a quick swipe.
